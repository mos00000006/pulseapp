PULSE Sales — operational source build, 18 October 2026

No fictitious product records or sample prices are included.

Features available locally: product catalogue and CSV import, cart, measurements, customer records, estimates, print/PDF via browser, quotation status and reports.

PRODUCTION BLOCKERS: This package is not yet a deployed multi-user system. It does not include secure server-side login, shared cloud database, actual PULSE product/price/stock data, or ERP synchronization. Browser localStorage is not an acceptable shared production database. Connect a secure backend, provision accounts and permissions, load approved PULSE stock file, configure domain and HTTPS, test before rollout. Do not use it for confirmed stock promises until ERP sync is configured.

To preview locally, serve folder via HTTPS or local web server and open index.html.
